# final_analysis
Итоговая работа обучения по курсу "Аналитик данных" Финансовый университет

**Тема:** Исследование покупательского поведения и эффективности торговых центров на основе транзакционных данных с применением методов разведочного анализа (EDA) и RFM-сегментации

**Бизнес-вопрос:** Выявить ключевые паттерны покупательского поведения, оценить эффективность различных торговых центров (моллов), провести базовую сегментацию клиентов (RFM) и сформулировать обоснованные рекомендации для управления моллами.

**Исходные данные:** [customer_shopping_data.csv](customer_shopping_data.csv) Датасет содержит информацию о покупках в 10 различных торговых центрах (Стамбул) за период с 01-01-2021 по 08-03-2023.

**Очищенные данные:** [customer_shopping_data_clean.csv](customer_shopping_data_clean.csv)

**Metadata:** [metadata.md](metadata.md)

**Ноутбук:** [research.ipynb](research.ipynb)

**Визуализация в DataLens:** [https://datalens.yandex/tuxs5cz1pe98c?_share_link=public](https://datalens.yandex/tuxs5cz1pe98c?_share_link=public)

**Итоговый отчёт:** [https://docs.google.com/document/d/1ZB0PsXGLoDgDimw5Bnm82fYDpR4y_jE5/edit?usp=sharing&ouid=104968886814341842005&rtpof=true&sd=true](https://docs.google.com/document/d/1ZB0PsXGLoDgDimw5Bnm82fYDpR4y_jE5/edit?usp=sharing&ouid=104968886814341842005&rtpof=true&sd=true)


В работе использовался датасет `customer_shopping_data.csv`, содержащий `99,457` транзакций с 9 полями: идентификаторы чеков и клиентов, пол, возраст, категория товара, выручка, способ оплаты, дата и название торгового центра.

После предобработки: обработала даты в формате день/месяц/год, извлекла временные признаки (год, месяц, день недели), создала признак возрастные группы. Проверила данные на пропуски, дубликаты и отрицательные значения - данных с ошибками не обнаружено.

---

На этапе разведочного анализа выявила **критическую особенность**: каждый `customer_id` встречается только 1 раз - это означает, что каждый клиент совершил только ОДНУ покупку в ОДНОЙ категории. Поэтому классический RFM-анализ и анализ повторных покупок неприменимы.

Вместо этого провела сегментацию клиентов по сумме покупки через квантили (`Low`, `Medium`, `High`, `Premium`).

**Ключевые метрики:**
- Общая выручка: `120.5 млн`
- Средний чек: `1,210`, медианный чек: `971.68`
- Топ категория: `Clothing` (одежда) - `69 млн` выручки
- Топ торговый центр: `Mall of Istanbul`
- Основная аудитория: женщины (доля выручки `60%` против `400%` у мужчин), возрастная группа `50+`

Для визуализации создала [дашборд в Yandex DataLens](https://datalens.yandex/tuxs5cz1pe98c?_share_link=public) с 7 ключевыми графиками:

1. **Общая выручка за весь период** - индикатор
2. **Выручка по торговым центрам** - горизонтальная столбчатая диаграмма
3. **Выручка по категориям** - столбчатая диаграмма
4. **Динамика выручки по дням недели** - столбчатая диаграмма
5. **Динамика выручки по месяцам** - столбчатая диаграмма
6. **Распределение выручки по полу** - круговая диаграмма
7. **Распределение выручки по возрастной группе** - круговая диаграмма

Создала 3 селектора: Категория, День недели, Возрастная группа

##### Ключевые выводы
1. **Основной драйвер продаж** — одежда, на которую приходится более половины выручки.
2. **Целевая аудитория** — женщины и покупатели старше 36 лет.
3. **Топ-3 ТЦ** (`Mall of Istanbul`, `Kanyon`, `Metrocity`) генерируют `~54%` всей выручки.
4. Продажи стабильны по дням недели и месяцам, без выраженной сезонности.
